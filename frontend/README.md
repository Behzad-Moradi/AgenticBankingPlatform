# Agentic Banking Platform frontend

A focused React interface for authenticating with and demonstrating the existing FastAPI banking assistant.

## Run locally

1. Start the backend on `http://127.0.0.1:8000`.
2. Install dependencies with `npm install`.
3. Start the frontend with `npm run dev`.
4. Open `http://localhost:5173`.

Vite proxies `/api` to the backend during development. To use another API URL, copy `.env.example` to `.env` and change `VITE_API_BASE_URL`.
